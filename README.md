# Northstar Vocab UAT

English vocabulary learning tool built with Vite, React, and TypeScript.

## Local Commands

```bash
npm install
npm run dev
npm run build
npm run test
npm run test:coverage
npm run test:e2e
```

`npm run dev` starts the Vite development server at `http://localhost:5173`.

`npm run test:coverage` enforces 90% minimum coverage for lines, branches, functions, and statements.

`npm run test:e2e` starts the app with Vite and runs Playwright desktop and mobile browser tests.
